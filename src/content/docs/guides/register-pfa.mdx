	PFA (Persoană fizică autorizată) — робота на себе в Румунії, подібна до українського ФОП. Переклади оплачуються окремо; адреса SOLO входить у підписку.
</Summary>

## Кроки

<Steps>

1. **[Оберіть сервіс і коди діяльності](#вибір-сервісу).**
2. **[Підготуйте адресу](#адреса-pfa)** та **[переклади](#переклади)** за вимогами обраного сервісу.
3. **[Подайте заявку й отримайте свідоцтво](#подача-й-результат).**
4. **[Підключіть SOLO](#обслуговування-в-solo)** для ведення PFA, якщо обрали цей сервіс.

</Steps>

## Вибір сервісу

### Вартість і вибір

Приклади сервісів, не рекомендація. Вибирайте після підтвердження, що сервіс працює з вашим статусом.

| Сервіс | Вартість | Коли розглядати |
| --- | --- | --- |
| [Aprobat](https://www.aprobat.ro/infiintare-pfa) | 499 лей + TVA | Потрібна окрема послуга реєстрації; бухгалтерію обиратимете окремо |
| [SOLO](https://www.solo.ro/infiintare-pfa-pfi) | Реєстрація включена в абонплату 139 лей/місяць | Хочете реєстрацію та подальше обслуговування в одному сервісі |

Для реєстрації виберіть сервіс нижче. До оплати отримайте розрахунок із ПДВ, перекладами й адресою за потреби та умови повернення коштів у разі відмови.

<Tabs>
<TabItem label="Aprobat">

Відкрийте [форму зв’язку Aprobat](https://www.aprobat.ro/contact). Вкажіть українське громадянство, точну назву документа про перебування та майбутні послуги. Попросіть підтвердити прийняття справи, перелік документів, перекладів і повну вартість до оплати.

</TabItem>
<TabItem label="SOLO">

SOLO реєструє PFA з адресою в Бухаресті, яку надає сервіс. Реєстрація входить в абонплату за ведення PFA; окремого тарифу лише на відкриття немає. За [умовами сервісу](https://www.solo.ro/pricing), після припинення підписки адресу потрібно змінити протягом 45 днів.

:::note[Тимчасовий захист]
SOLO приймає румунський документ про тимчасовий захист (*permis de ședere pentru beneficiarii protecției temporare*). У грудні 2024 року учасник спільноти відкрив PFA через SOLO з цим документом і перекладом диплома.
:::

Відкрийте [сторінку SOLO](https://www.solo.ro/infiintare-pfa-pfi) і виберіть **Vreau PFA cu SOLO**.

</TabItem>
</Tabs>

### Вид діяльності

Виберіть у [класифікаторі CAEN Rev. 3](https://www.onrc.ro/documente/anunturi/CAEN-Rev.3_structura-completa.pdf) коди для послуг, які продаватимете. CAEN — румунський аналог КВЕД. Передайте Aprobat коди разом із коротким описом роботи або вкажіть їх в анкеті SOLO.

| Код | Коли підходить |
| --- | --- |
| 6210 | Розробляєте ПЗ на замовлення |
| 6220 | Надаєте IT-консультації або керуєте комп’ютерними системами клієнта |

### Підтвердження досвіду

Aprobat і [SOLO](https://www.solo.ro/intrebari/ce-acte-sunt-necesare-pentru-infiintarea-unui-pfa) просять документ про підготовку або професійний досвід. Почніть із наявного диплома чи сертифіката за відповідним напрямом. [ONRC також перелічує](https://www.onrc.ro/index.php/ro/inmatriculari/persoane-fizice/persoane-fizice-autorizate-pfa?id=20) трудову книжку та інші докази професійного досвіду.

:::note[Немає диплома]
Попросіть роботодавця видати довідку з посадою, періодом роботи й обов’язками. Надішліть її консультанту як доказ досвіду для оцінки; прийнятність конкретної довідки треба підтвердити до замовлення перекладу.
:::

Не замовляйте визнання диплома автоматично: у переліку ONRC підтвердження кваліфікації є умовною вимогою для діяльності, яку регулюють спеціальні правила. Попросіть консультанта пояснити, що потрібно саме для обраних кодів.

### Чек-ліст

- [ ] **Документ про перебування** - точна назва й тип: тимчасовий захист або посвідка.
- [ ] **Опис послуг** - що робитимете для клієнтів, обрані CAEN Rev. 3.
- [ ] **Документ про підготовку або досвід** - наявний диплом, сертифікат чи доказ досвіду для оцінки сервісом.
- [ ] **Відповідь Aprobat** - прийняття справи, перелік документів і розрахунок вартості, якщо обрали Aprobat.

## Адреса PFA

Оформіть **sediu profesional** — адресу реєстрації PFA. SOLO надає адресу в Бухаресті, включену в підписку. Для Aprobat виберіть один із варіантів нижче.

<Tabs>
<TabItem label="Власне або орендоване житло">

<Steps>

1. **Передайте Aprobat документ на приміщення.** Для власного житла — документ про власність; для орендованого — чинний договір. Попросіть перевірити, чи він дозволяє використати адресу для PFA.
2. **Зверніться до власника, якщо потрібен окремий договір.** Aprobat включає підготовку договору оренди (*închiriere*) або безоплатного користування (*comodat*) у пакет реєстрації. Передайте проєкт власникам для підписання.
3. **Збережіть підписаний документ** для пакета в ONRC. Повідомте консультанту, чи працюватимете за цією адресою, чи вона потрібна лише для реєстрації.

</Steps>

:::note[Співвласники]
Aprobat вимагає згоди всіх власників. Не вказуйте, що діяльності за адресою немає, якщо фактично працюватимете там: від цього залежать додаткові документи для житлового приміщення.
:::

</TabItem>
<TabItem label="Адреса від сервісу">

Замовте в Aprobat **găzduire sediu profesional** — адресу для реєстрації. Отримайте пропозицію з адресою, строком і ціною; перевірте порядок пересилання пошти. Підпишіть договір і збережіть його для реєстраційного пакета.

</TabItem>
</Tabs>

### Чек-ліст

- [ ] **Право користування адресою** - для Aprobat: документ про власність, оренду, безоплатне користування або договір адреси від сервісу.
- [ ] **Дані про роботу за адресою** - для заяви про місце діяльності через Aprobat.

## Переклади

:::note[Лише за потреби]
Цей етап потрібен для документів не румунською мовою. Для SOLO перекладіть іноземний диплом у авторизованого перекладача без нотаріального засвідчення. Для Aprobat перекладайте документи з погодженого пакета.
:::

<Steps>

1. **Надішліть документи <a href={translatorContacts}>авторизованому перекладачу</a>.** Зазначте, що переклад потрібен для реєстрації PFA в ONRC. Для Aprobat передайте погоджені вимоги, зокрема до засвідчення.
2. **Отримайте переклади у погодженому форматі.** Звірте написання імені з паспортом і номери документів. Збережіть файли для обраного сервісу та паперові примірники, якщо їх замовляли.

</Steps>

### Чек-ліст

- [ ] **Документи для перекладу** - лише з погодженого пакета.
- [ ] **Вимоги до перекладу** - мова, формат і засвідчення за обраним сервісом.
- [ ] **Готові переклади** - імена й номери звірені з оригіналами.

## Подача й результат

<Tabs>
<TabItem label="Aprobat">

Передайте консультанту скани паспорта, документа про перебування, документа на адресу, підтвердження підготовки або досвіду та потрібні переклади. Це пакет для роботи сервісу; заяви й декларації для ONRC готує Aprobat.

<Steps>

1. **Звірте підготовлений пакет.** Перевірте ім’я, адресу й CAEN. Назва PFA включає прізвище, ім’я та *persoană fizică autorizată*; резервування назви входить у послугу Aprobat.
2. **Підпишіть за посиланням від сервісу.** Aprobat описує дистанційну перевірку особи й підписання без власного електронного підпису. Збережіть копії підписаного пакета.
3. **Отримайте підтвердження подачі та номер заяви в ONRC.** Додаткові документи передавайте через консультанта, який супроводжує справу.
4. **Після схвалення завантажте видані ONRC файли.** Перевірте ім’я, адресу й види діяльності. Збережіть саме отримані електронні документи з підписом ONRC.

</Steps>

:::note[Податкова довідка]
Відомості з *cazier fiscal* ONRC отримує від ANAF (податкової служби) самостійно. Для іноземця, який не зареєстрований у податковій Румунії, передбачена окрема засвідчена заява; її застосовність і текст має визначити консультант.
:::

**Результат**

| Документ | Що перевірити |
| --- | --- |
| Свідоцтво про реєстрацію — *certificat de înregistrare* | CUI — податковий номер PFA, ім’я та адреса |
| Рішення реєстратора — *încheierea registratorului* | Рішення щодо вашої заяви |
| Підтвердження діяльності — *certificate constatatoare* | Зареєстровані види й місця діяльності |

:::caution[До першого рахунку]
Отримання документів завершує реєстрацію. Подальший податковий облік і налаштування виставлення рахунків — окрема робота з обраним бухгалтером або сервісом.
:::

</TabItem>
<TabItem label="SOLO">

1. **Заповніть анкету** на [сторінці SOLO](https://www.solo.ro/infiintare-pfa-pfi). Вкажіть коди CAEN і завантажте документ про тимчасовий захист та запитані документи про освіту або досвід.
2. **Оплатіть перший рахунок.** SOLO підготує та подасть пакет до ONRC і надішле номер заяви. Збережіть його.
3. **Збережіть свідоцтво.** Після схвалення SOLO передасть *certificat de înregistrare* з CUI.

</TabItem>
</Tabs>

### Чек-ліст

- [ ] **Паспорт і документ про перебування** - для обраного сервісу.
- [ ] **Документ на адресу PFA** - для Aprobat.
- [ ] **Підтвердження підготовки або досвіду** - диплом або інший документ для сервісу.
- [ ] **Переклади** - для документів, які їх потребують.
- [ ] **Банківська картка** - для оплати підписки SOLO.

## Обслуговування в SOLO

[SOLO](https://www.solo.ro/intrebari/ce-face-solo-pentru-mine) допомагає виставляти рахунки, обліковувати витрати та подавати звітність. Якщо відкрили PFA через SOLO, продовжуйте користуватися своїм обліковим записом. Якщо зареєстрували PFA через Aprobat, [створіть обліковий запис SOLO](https://www.solo.ro/) та оберіть **Am PFA**. Завантажте свідоцтво, рішення реєстратора і *certificate constatatoare* в **Documente → Acte înființare**. [Інструкція SOLO](https://help.solo.ro/hc/ro/articles/38343246761245-Ghid-complet-inregistrare-amPFA-pasi-si-documente).

Для представництва перед ANAF (податковою службою) оформіть нотаріальну довіреність за зразком SOLO і передайте оригінали за інструкцією сервісу. Нотаріус оплачується окремо. Повідомте сервісу країни клієнтів і узгодьте облік та e-Factura перед першим рахунком. Якщо вже працювали, передайте попередню декларацію, рахунки й документи про витрати поточного року.

### Чек-ліст

- [ ] **Країни клієнтів** - для узгодження обліку.
- [ ] **Попередня звітність, рахунки й витрати** - якщо вже працювали.
